# TAIS — разработка

## Подготовка (один раз)

```powershell
git clone https://github.com/taglatipov-dotcom/TAIS.git
cd TAIS
python -m venv .venv
.venv\Scripts\python -m pip install -r Backend\requirements-dev.txt
cd Frontend; npm install; cd ..
cd Desktop;  npm install; cd ..
cd Mobile;   npm install; cd ..      # если нужна мобильная версия
```

## Запуск

Три окна терминала:

```powershell
# 1. сервер
cd Backend; ..\.venv\Scripts\python -m tais            # http://127.0.0.1:8765/api/health
# 2. интерфейс с горячей перезагрузкой (прокси /api на сервер)
cd Frontend; npm run dev                               # http://127.0.0.1:5173
# 3. (по желанию) то же в окне программы
cd Desktop; npm run dev
```

## Тесты

```powershell
cd Backend; ..\.venv\Scripts\python -m unittest -v     # генератор, акты, листы, статистика
cd Mobile;  npm test                                   # JS-генератор против эталонов Python
```

После изменения правил генератора (`Backend/tais/generator`) — перенести изменения в
`Mobile/src/generator/`, обновить эталоны (`.venv\Scripts\python Mobile\tools\make_golden.py`)
и `docs/Правила сборки лесов.md`.

Раскладку листа A3 можно посмотреть без nanoCAD:
`cd Backend; ..\.venv\Scripts\python tools\sheet_preview.py 21x1x4.7 2x1x10.2` — SVG появятся
в `Backend\tools\preview`.

## Сборка установщика

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1                       # полная версия
powershell -ExecutionPolicy Bypass -File build.ps1 -DemoUntil 2026-12-31 # демо до даты
```

Результат — `Desktop\dist\`. Получателю не нужны ни Python, ни Node.js.

- Инструменты electron-builder (NSIS) по умолчанию качаются с зеркала npmmirror
  (GitHub бывает недоступен); своё зеркало — переменная `ELECTRON_BUILDER_BINARIES_MIRROR`.
- Демо: дата вшивается в `Backend/tais/_build_info.py` (создаёт `build.ps1`, в git не попадает).
  После даты сервер отвечает на `/api/*` ошибкой `demo_expired`; защита от перевода часов —
  `tais/demo.py`.
- Иконка вшивается в exe через `resedit`, поэтому в `Desktop/package.json` стоит
  `signExecutable: false` (не `signAndEditExecutable: false`).
- `Library/` (`Шаблон.dwg`, `Веса элементов.csv`) входит в установщик как `resources\library`.
  Обновить шаблон или спецификацию для всех — заменить файл в `Library` и пересобрать.

## Выпуск версии

1. Поднять версию в `Desktop/package.json` (`"version"`).
2. Закоммитить и поставить тег:
   ```powershell
   git commit -am "Версия 0.2.0"
   git tag v0.2.0
   git push; git push origin v0.2.0
   ```
3. GitHub Actions (`.github/workflows/release.yml`) соберёт установщик и APK и опубликует Release.

## Структура

| Папка | Что внутри |
|---|---|
| `Backend/tais/generator` | Генератор: разбивка пролётов, модель (сетка + ячейки), правила раскладки, спецификация, радиальные леса |
| `Backend/tais/cad` | nanoCAD через COM: поиск, запуск, вставка блоков в копию шаблона, печать; `views.py` — виды и размеры листа A3 |
| `Backend/tais/app.py` | API (FastAPI) и раздача собранного интерфейса |
| `Backend/tais/db.py`, `acts.py` | Акты (SQLite), номер ИС, основная надпись |
| `Backend/tests` | Тесты (в т.ч. сравнение с чертежами архива) |
| `Backend/tools` | Предпросмотр листа A3, разбор таблицы спецификации |
| `Frontend` | Интерфейс (React + antd + Tailwind) |
| `Desktop` | Оболочка Electron, настройки установщика, иконки |
| `Mobile` | Android-версия (Capacitor), генератор на JS |
| `Library` | Встроенная библиотека: `Шаблон.dwg`, `Веса элементов.csv` |
| `docs` | Правила сборки лесов, PDF-инструкция и презентация (`docs/src` — исходники) |
| `build.ps1` | Сборка установщика одной командой |

Данные пользователя — `%APPDATA%\TAIS`: `tais.db`, `pictures\`, `settings.json`, `logs\backend.log`.
